### The rhythm for each topic

1. **Intuition.** Read the plain-words idea and look at the pictures first. If you can explain the picture to a friend, you understand the idea.
2. **How it works.** Follow the step-by-step trace with a pencil. Redraw the tree, table or graph at each step yourself.
3. **Python implementation.** Type the code in; don't paste it. Run it, then change the input and predict the output before running again.
4. **Problems.** Solve them on paper or in code. Several are the lab programs for this course.
5. **Quiz.** 10 questions that mark themselves and explain every answer. Pass at **60%** to tick the topic off.
6. **GATE-style practice.** Four exam-level questions, each with a full worked solution. Try each one under time pressure, about 3 minutes, before reading the solution.

At the end of each course outcome there is a **CO test**: 20 questions drawn at random from that CO's quizzes.

### Setting up Python

All code on this site is plain **Python 3.10 or later**, using only the standard library.

1. Install Python from [python.org](https://www.python.org/downloads/). On Windows, tick *Add Python to PATH*.
2. Save a program as, for example, `bst.py`, and run it:

```bash
python bst.py
```

Each implementation ends with a short demo that prints its results, so you can check it works straight away.

### GATE question formats

GATE CSE uses three kinds of question, and the practice sections use all three:

| Type | What you do | How it is marked here |
| --- | --- | --- |
| **MCQ** | choose the one correct option | right or wrong |
| **MSQ** | choose **all** correct options (one or more) | right only if you pick exactly the correct set |
| **NAT** | type a number | right if it matches (within the stated range, for decimals) |

In the real exam, MCQs carry negative marks for wrong answers, but MSQs and NATs do not. The practice here does not deduct marks.

These questions are **original practice questions** written in the GATE style, not copies of past papers. For past papers, use the official GATE website.

### Your marks

The **My marks** page shows your best and latest score for every quiz, GATE-style set and CO test, with totals per course outcome. You can download your marks (CSV) or print them with your name and ID.

Marks are kept **only in this browser**. They never leave your device, and your instructor cannot see them unless you send the CSV or the printout. Clearing browser data or switching devices starts a fresh record. The answers are part of the page, so the quizzes are for practice, not for invigilated tests.
