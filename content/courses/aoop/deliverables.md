Each week produces four deliverables, all committed to the team repository, so marks for the continuous‑evaluation components come from the same evidence.

| Week | Practical | Skill A | Lecture | Skill B |
| --- | --- | --- | --- | --- |
| 1 | Core model + ≥ 8 invariant tests (`W1-P1`) | Domain map + invariant catalogue | Exit ticket: 3 invariants + doorway fix | Invariant classification + transition table draft |

| 3 | Allocator contract + 3 allocators (`W3-P3`) | Contract sheet + sequence diagram | 2 method contracts + LSP table | LSP violation worksheet |
| 4 | Shared contract suite + saboteur log (`W4-P4`) | Role interfaces + contract checklist | Type‑choice table + role split | JDK error diagnosis |

| 6 | God‑class teardown + `FeePolicy` (`W6-P6`) | Five green refactoring commits | Transition table + `BookingStatus.next` | Reports + design‑rule test + state diagram |
| 7 | `Result` + idempotent booking (`W7-P7`) | Failure taxonomy (12 rows) | Failure sort + pay‑at‑exit flow | Retry policy with numbers |
| 8 | Retry, breaker, outbox (`W8-P8`) | Compensation table + `CancellationService` | Breaker diagram + saga | Chaos report (5 seeds) |
